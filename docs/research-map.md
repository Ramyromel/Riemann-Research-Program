# Research Map

## Analytic formulations
- completed zeta function
- functional equation
- Hadamard product
- explicit formulas
- Mellin and Fourier representations

## Positivity
- Li-type criteria
- Weil criterion
- quadratic forms
- positive-definiteness and kernel methods

## Spectral approaches
- Hilbert-Polya
- self-adjoint operators
- trace-formula correspondence
- spectral convergence

## Finite approximations
- truncated prime and Euler data
- Galerkin and matrix approximations
- finite quadratic forms
- stability of spectral data under limits

## Verification
- exact arithmetic where possible
- interval and error bounds
- independent implementations
- adversarial numerical tests
- proof-assistant formalization when justified

## Initial critical question

Can one establish a rigorous finite-to-infinite construction in which the required positivity survives the limiting process and the limiting object is provably the Weil/Riemann object rather than merely a numerically similar surrogate?
