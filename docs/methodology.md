# Research Methodology

## Analyze -> Derive -> Test -> Attack -> Verify

Analyze established theory and locate exact open gaps.

Derive lemmas from explicit definitions and cited theorems. Every nontrivial inference must have a traceable dependency.

Test identities, asymptotics, spectral behavior, and candidate counterexamples with reproducible computation.

Attack proposed results by searching for counterexamples, hidden assumptions, domain failures, unjustified limit exchanges, and spectral-identification errors.

Verify results independently from declared inputs.

## Evidence hierarchy

1. Formal proof / independently checkable theorem.
2. Rigorous analytic derivation.
3. Exact symbolic verification.
4. Reproducible numerical evidence.
5. Heuristic evidence.

Lower-level evidence never substitutes for higher-level evidence.
