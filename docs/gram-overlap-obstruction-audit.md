# Gram/Overlap Obstruction Audit

**Status:** DERIVED STRUCTURAL AUDIT — NO RH CLAIM

## Objective

Test the first exact Gram candidate suggested by the prime-intersection route against the actual pole-neutral Prime–Weil arithmetic functional.

For
\[
x_q=\omega_q=1-\frac{\log q}{\log c},
\qquad
w_q=\frac{\Lambda(q)}{\sqrt q},
\]
a canonical positive overlap kernel is
\[
G_{qr}=w_qw_r\min(x_q,x_r).
\]

The question is whether the resulting source Gram form can represent
\[
-\sum_q w_qK_v(x_q)
\]
for arbitrary admissible \(v\).

## 1. Exact Gram representation of the candidate

For \(x_q\in[0,1]\), define
\[
\phi_q(t)=w_q\,\mathbf 1_{[0,x_q]}(t).
\]

Then
\[
\langle\phi_q,\phi_r\rangle_{L^2(0,1)}
=
w_qw_r\int_0^1
\mathbf1_{t\le x_q}\mathbf1_{t\le x_r}\,dt
=
w_qw_r\min(x_q,x_r).
\]

Therefore \(G=[G_{qr}]\) is positive semidefinite exactly.

This proves the candidate is a legitimate Gram object. It does **not** prove that it is the Weil form.

## 2. Immediate structural mismatch

The Prime–Weil arithmetic term is linear in the sampled scalar values
\[
K_v(x_q):
\qquad
Q_{\rm prime}(v;c)
=
-\sum_q w_qK_v(x_q).
\]

The Gram candidate is naturally a quadratic form in a vector of source coefficients \(a_q\):
\[
a^\top G a
=
\sum_{q,r}
a_qa_rw_qw_r\min(x_q,x_r).
\]

These have different dependency structures:

- Prime–Weil: one sum over sources, with a source value generated by the test function \(v\).
- Candidate Gram: two sums over sources, with an independently chosen coefficient vector \(a\).

Therefore an identification requires a nontrivial linear map
\[
a=A(v)
\]
and an exact identity
\[
A(v)^\top G A(v)
=
-\sum_q w_qK_v(x_q)
\]
for every admissible \(v\).

No such map is assumed here.

## 3. Stronger obstruction: sign before archimedean completion

The overlap Gram matrix \(G\) is PSD, so
\[
a^\top G a\ge0.
\]

But the arithmetic Prime block is
\[
Q_{\rm prime}(v;c)=-\sum_qw_qK_v(x_q),
\]
and \(K_v(x)\) is not pointwise nonnegative for a general real-even \(v\). It is a reflected autocorrelation and can have either sign away from \(x=1\).

Thus the prime block cannot be identified with the canonical positive overlap Gram form by a coefficient-independent sign convention alone.

This is an obstruction to the **naive** overlap identification, not a proof that no more elaborate Gram/Schur representation exists.

## 4. Exact relation to the existing \(K_v\)

The actual kernel is
\[
K_v(x)=2\int_0^xT_v(t)T_v(x-t)\,dt.
\]

For fixed \(x\), this is bilinear in \(T_v\), hence quadratic in the Galerkin coefficients \(v\). Consequently
\[
-\sum_qw_qK_v(x_q)
\]
is itself a quadratic form in \(v\).

This means the correct Gram question is not to construct a Gram matrix whose coordinates are arbitrary prime-source coefficients. The correct target is:

> Can the quadratic form in \(v\), obtained after summing the prime-source overlap functionals, be represented as \(B^\ast B\) or as a Schur complement after incorporating the archimedean term?

That is a substantially sharper formulation.

## 5. Kernel-level reformulation

Let \(T_v\) be the finite-dimensional function generated by \(v\). Define
\[
\mathcal P_c[T]
=
-2\sum_{q\le c}
w_q
\int_0^{x_q}
T(t)T(x_q-t)\,dt.
\]

After changing variables, each term couples pairs
\[
(t,x_q-t)
\]
whose sum equals the prime-power source coordinate \(x_q\).

Thus the arithmetic block is a weighted collection of **sum-level intersections**, not a simple pairwise distance kernel.

This is the key structural distinction.

The user's "intersection points" intuition therefore maps more naturally to the level sets
\[
t+s=x_q
\]
than to the distances \(|q-r|\) between primes.

## 6. Candidate positive representation

A positive representation would need to transform the sum-level bilinear form into something like
\[
\mathcal P_c[T]+\mathcal A_c[T]
=
\int |\Phi_T(z)|^2\,d\mu_c(z)
\]
or a finite-dimensional equivalent
\[
Q_{\rm PN}(v;c)=v^\ast H_{c,N}v,
\qquad
H_{c,N}=B^\ast B.
\]

The archimedean term is essential because the prime block alone has no established positivity.

## 7. Falsification criterion

A finite exact computation may discover a negative eigenvalue of the proposed \(H_{c,N}\), but that only falsifies that proposed representation or parameter regime.

A positive spectrum does not prove positivity for all \(N,c\), and neither finite positivity nor spectral matching proves RH.

## 8. Conclusion

The first canonical intersection Gram kernel
\[
w_qw_r\min(x_q,x_r)
\]
is mathematically valid and PSD, but it does **not** directly reproduce the Prime–Weil arithmetic functional.

The obstruction is structural:

\[
\boxed{
\text{source-pair overlap}
\neq
\text{sum-level autocorrelation }K_v(x_q)
}
\]

The research route should therefore move from **prime-source Gram matrices** to **sum-level convolution/Toeplitz/Hankel structure in the test-function coordinate**.
