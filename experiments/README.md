# Experiments

Computational work is exploratory and verification-oriented.

Rules:
- Every experiment states its mathematical target.
- Inputs and numerical precision are recorded.
- Error estimates or stability checks are included where applicable.
- Code is reproducible.
- Numerical agreement is never presented as a proof of RH.

The first experimental branch will investigate finite approximations to Weil-type quadratic forms and the stability of their spectral and positivity properties under controlled enlargement.
