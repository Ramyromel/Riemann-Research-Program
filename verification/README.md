# Verification

Verification is separate from discovery.

## Requirements

A claimed theorem must include:
- exact statement;
- assumptions;
- dependency list;
- proof or derivation;
- independent check;
- known limitations.

Computational results must include:
- source code;
- deterministic inputs;
- precision;
- error or stability information;
- reproducible command.

## Promotion rule

PROVED is reserved for complete mathematical arguments. Numerical evidence may motivate a theorem but cannot close an analytic gap.
